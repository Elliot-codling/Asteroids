# Asteroids
A small game that has rocks floating down towards the player.\
The objective of your mission is to test your flighting skills. You must weave through the rocks using either AD or arrow keys.

Be careful! After 10 sets of rocks, the speed will double.

### Requirements
- Pygame 2.0 or newer
- Python 3.6 or newer

Since Asteroids was built with the Raspberry Pi in mind, a chart has been created to show which series of model would be supported.

| Raspberry Pi Series Model | Recommended Setting |
| :---: | :---: |
| 1B | Not supported |
| 2B | Not supported |
| 3B | Performance Mode: ON |
| 4B | Performance Mode: OFF |
| 5B | Performance Mode: OFF |
| **Zero Models** | **Recommended Settings** |
| W | Not supported |
| 2W | Performance Mode: ON & Overclock: 1.2GHz |

For the rest of the world: Dual core 1.5Ghz, anything from 2012 or later.
